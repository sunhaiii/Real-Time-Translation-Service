음성 파이프라인 데이터 흐름 (Voice Pipeline)

클라이언트가 말하면 → STT → 번역 → (선택) TTS → 세션 전체에 브로드캐스트되는 흐름입니다.

sequenceDiagram participant Client as 클라이언트 브라우저 participant FE as Frontend participant WS as WebSocket participant BE as Backend participant STT as Google STT participant Gemini as Gemini 번역 participant TTS as Google TTS participant Counselor as 상담자 브라우저 Client->>FE: 마이크 PCM (AudioWorklet) FE->>WS: type: audio_stream, data: base64 WS->>BE: WebSocket 메시지 BE->>STT: 스트리밍 음성 STT-->>BE: 인식 텍스트 (원문) BE->>BE: DB에 메시지 저장 (선택) BE->>Gemini: 원문 텍스트 Gemini-->>BE: 번역 텍스트 opt TTS 사용 시 BE->>TTS: 번역 텍스트 TTS-->>BE: MP3 base64 end BE->>WS: broadcast to session WS->>FE: transcription, translation_complete, tts_audio FE->>Client: 화면 표시 + TTS 재생 FE->>Counselor: 동일 메시지 표시 (같은 세션)
