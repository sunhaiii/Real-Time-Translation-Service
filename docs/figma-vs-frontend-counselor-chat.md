# Figma 상담자 화면_채팅 vs 현재 프론트엔드 비교

Figma 시안 **상담자 화면_채팅** (1440×900)과 현재 구현된 **CounselorScreen** 차이를 정리했습니다.

---

## 1. 전체 레이아웃

| 항목 | Figma 시안 | 현재 프론트엔드 | 비고 |
|------|------------|-----------------|------|
| **캔버스** | 1440×900 | `max-w-[1440px]` `min-h-[900px]` `h-screen` | ✅ 동일 |
| **구성** | Sidemenu + Main( Top + 채팅 + 입력 ) | 동일 구조 | ✅ 동일 |

---

## 2. Sidemenu (좌측 248px)

| 항목 | Figma | 현재 구현 | 비고 |
|------|--------|-----------|------|
| **너비** | 248×900 | `w-[248px]` | ✅ 동일 |
| **Workspace** | 248×56 | `h-14` (56px) + "Workspace" 텍스트 | ✅ 동일 |
| **중간 영역** | Frame 248×752 (메뉴 등) | `flex-1` 빈 영역 | ⚠️ 시안에는 메뉴 리스트 등이 있을 수 있음, 현재는 비어 있음 |
| **Profile** | 248×92, Profile 208×52 | `h-[92px]` + 아이콘 + "Profile" | ✅ 동일 |

---

## 3. Top 바 (1192×56)

| 항목 | Figma | 현재 구현 | 비고 |
|------|--------|-----------|------|
| **높이** | 56px | `h-14` (56px) | ✅ 동일 |
| **좌측** | Frame 60×24 (로고/아이콘) | `w-[60px]` + 24×24 placeholder | ✅ 동일 |
| **우측** | **button_rounded 1개** (93×36) | **버튼 2개**: 내 언어 + 상대방 언어 (각 `minWidth: 93`, `h-9` 36px) | ❌ **다름** – 시안은 버튼 1개, 구현은 언어 2개로 기능 확장 |
| **버튼 스타일** | 93×36 rounded | `rounded-full` `h-9` `minWidth: 93` | ✅ 비슷 |

**요약:** 시안은 Top에 버튼 1개, 현재는 내 언어/상대방 언어 드롭다운 2개로 되어 있어 **구성이 다름**. (기능상 필요에 따른 확장)

---

## 4. 채팅 영역 (메시지 목록)

| 항목 | Figma | 현재 구현 | 비고 |
|------|--------|-----------|------|
| **컨테이너** | Frame 1000006886: **1192×728** | `flex-1 min-h-0 overflow-y-auto` + `px-4 py-4` | ⚠️ 시안은 높이 728px 고정, 구현은 flex로 가변 |
| **메시지 스타일** | (시안 상세 미확인) | 본인: `bg-indigo-500` 흰글, 상대: 흰 배경 + 테두리, `rounded-2xl` | ⚠️ 말풍선 색/형태는 Figma에서 확인 필요 |
| **빈 상태** | (미확인) | "상담을 시작하세요" | - |

**요약:** 영역 역할은 동일. 시안은 **채팅 영역 높이 728px**, 구현은 **flex-1**로 남는 공간 전부 사용.

## 5. 입력 영역 (하단)

| 항목 | Figma | 현재 구현 | 비고 |
|------|--------|-----------|------|
| **영역 높이** | Frame 1000006887: **1192×116** | `ChatInput` + 상단 `border-t` | ⚠️ 시안 116px, 구현은 콘텐츠 높이에 따름 |
| **입력창** | (Prompt input 스타일) | `useFigmaStyle={true}`: rounded-full, h-[52px], #d7d7d7 / #8ab4df / #005cb9 | ✅ Figma 스타일 적용됨 |
| **구성** | (시안 상세 미확인) | 첨부 버튼 + input + 마이크 + 전송 (36×36) | ⚠️ 시안에 첨부 버튼 유무 확인 필요 |

**요약:** ChatInput은 Figma 스타일 적용. **전체 입력 영역 높이**만 시안(116px)과 다를 수 있음.

## 7. 차이 요약 (우선 반영 권장)

1. **Top 바**
   - 시안: 버튼 **1개** (93×36).
   - 구현: **2개** (내 언어, 상대방 언어).
   - → 디자인 완전 일치를 원하면 1개로 줄이거나, 시안 업데이트로 2개 구성 허용 여부 결정 필요.

2. **채팅 영역 높이**
   - 시안: **728px** 고정.
   - 구현: **flex-1** 가변.
   - → 900 - 56(Top) - 116(입력) = 728px로 맞추려면 메인을 flex가 아닌 고정 높이로 줄 수 있음.

3. **입력 영역 높이**
   - 시안: **116px**.
   - 구현: 패딩 + 52px 입력창 등으로 실제 높이는 다를 수 있음.
   - → 입력 래퍼에 `min-h-[116px]` 또는 `h-[116px]` 적용 시 시안과 맞출 수 있음.

4. **Sidemenu 중간**
   - 시안: 메뉴 등 콘텐츠 가능성.
   - 구현: 빈 `flex-1`.
   - → Figma에서 메뉴 구조 확인 후 동일하게 채우기.

5. **설정 UI**
   - 시안: 설정 모달(440×344 등) 존재.
   - 구현: 없음.
   - → 별도 작업으로 설정 화면 추가 필요.

---

## 8. 일치하는 부분

- 전체 폭 1440px, 높이 900px 대응.
- Sidemenu 248px, Workspace 56px, Profile 92px.
- Top 56px, 좌측 60px 영역.
- 메인 1192px, 채팅 + 입력 구조.
- ChatInput Figma 스타일(색상, rounded-full, 52px 입력창).
- 언어 선택 드롭다운 241px, 48px 아이템, 국기 사용.
